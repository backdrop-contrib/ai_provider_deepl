# AI Provider DeepL

Translate text and HTML in Backdrop with DeepL. Choose the default style or request more formal or more informal wording for supported languages.

## Installation

Install and enable this module with AI and Key. [Backdrop module installation guide](https://backdropcms.org/user-guide/modules)

Store your service credentials using the Key module. Choose the provider in **Configuration → AI → Settings → Providers**. [Setup and troubleshooting](https://github.com/backdrop-contrib/ai_provider_deepl/wiki)
